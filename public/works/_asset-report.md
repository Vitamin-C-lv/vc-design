## 青花造境 分步截图

本次实际推进 2 步；桌面端先点击“跳过教程 / SKIP TUTORIAL”，随后通过页面可见的完成按钮推进：“完成塑形” → “完成绘饰”。在第 03 工序“开始施釉”处按钮仍需先调节釉层，无法无条件继续，因此如实停止。移动端另抓取初始的第 01 工序画面。

### step-01.png
- 工序主题：02 青花绘饰 / PORCELAIN PAINTING；白色坯体进入钴蓝绘饰阶段。
- 逐字标题与文案：“PORCELAIN CREATION STUDIO · 02”“青花绘饰”“PORCELAIN PAINTING”“以钴蓝为墨，让纹样沿器物表面生长。”
- 画面与 UI：深墨绿粒子背景、右侧白色器物；左下有“绘饰控制”、画笔/橡皮/撤销/重做/清空、笔触与浓淡滑杆、本地纹样生成“LOCAL PATTERN SUGGESTIONS”及“AI生成纹样 / 换一组 / 清除AI纹样”；右下显示“操作方式”“左键落笔 · 右键或空格拖动旋转”和按钮“完成绘饰”，底部进度“02 / PAINTING”。

### step-02.png
- 工序主题：03 清釉覆彩 / TRANSPARENT GLAZING；白色器物进入透明釉覆盖阶段。
- 逐字标题与文案：“PORCELAIN CREATION STUDIO · 03”“清釉覆彩”“TRANSPARENT GLAZING”“一层清釉由上而下覆盖坯体，封存笔意，也等待火焰完成最后的显色。”
- 画面与 UI：深墨绿粒子背景、右侧白色器物与底部圆形台面；左下有“釉层厚度”“表面光泽”两条滑杆，右下显示“调节釉层后开始施釉”和按钮“开始施釉”，底部进度“03 / GLAZING”。

### mobile-step-01.png
- 工序主题：01 数字拉坯 / THROWING WORKBENCH；移动端初始画面展示成形中的金色器物。
- 逐字标题与文案：“PORCELAIN CREATION STUDIO · 01”“数字拉坯”“THROWING WORKBENCH”“以轮为轴，在旋转中建立属于你的器型。”
