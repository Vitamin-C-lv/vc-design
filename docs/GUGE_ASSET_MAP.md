### 三条必须纠正的现状问题

1. **标题混用**：素材里同时存在「梦回古格」「古格拾忆录」「数字重建古格王朝文化遗产」「基于 RAG 增强生成式 AI 的古格王朝智能交互 VR 游戏设计」。站点当前标题是「古格王朝 AI 智能导览系统」——与素材里的任何一个都不一致。
2. **素材利用率极低**：站点 `public/works/guge/` 只有 3 张风景 + 1 张旧总海报 + 1 张三层图 + 1 段 12s 循环。项目最有力的证据（4 张展板、人物长卷、Unity 实机、3D 过程、考古考据）全部没有进页面。
3. **PPT/展板被当成「资料来源」**：它们本身是项目成果，也是最直接的「VC 能把复杂项目讲清楚」的证据，当前完全没有作为能力展示。

**PPT 文本中的权威事实（必须原样使用，不得改写）**

- 遗址现状：*「在半山腰一个逼仄的洞窟里，我们遇到了一位当地居民。他日复一日地守在这里，只为保护里屋墙上仅存的壁画。」*
- 消逝：*「那些见证过历史的精美壁画和石窟，正随着岁月的剥蚀和自然环境的恶化，逐渐从世人的记忆中褪色。」*
- 考据：**「参考资料：1991 年《古格故城》考古报告」**；*「查阅 1991 年《古格故城》考古报告，并与札达县博物馆馆藏文物进行仔细比对，确保数字重建的准确性与严谨性。」*
- 考据结论句：**「数字重建并非凭空想象，而是建立在严谨的史料考证之上。」**
- 建模：*「通过实景扫描技术获取了古格王朝遗址的精确数据，并使用『中心聚焦式梯度压缩』（LOD）技术」*；*「从白模到上色」*
- AI：*「我们用 RAG 知识库 + LLM 大语言模型 + 智能寻路算法让古格的历史『活』了起来」*；*「大模型赋予她灵动的表达，语音克隆还原鲜活的声线，RAG 知识库则为每一段讲述注入严谨的史实」*
- 果沃琴：*「循着残破壁画的痕迹，补全丢失的内容，还原壁画的真实样貌，以此解锁尘封的乐谱，奏响曾在这片土地上久久回响的古老乐曲。」*
- 叙事：*「我们围绕少女『梅朵』的成长与情感线，构建了完整的人物关系网。作为玩家的向导与伙伴，梅朵不仅是剧情的推动者，更是连接过去与现在的纽带。」*

## 4. 素材处理规则

1. **保留原始素材**：`/mnt/c/...` 与附件路径下的原件**只读**，全程不修改、不移动。
2. **新版本单独输出**：Web 版本一律走 `scripts/assets/build-images.mjs` 的命名约定（`-480/-768/-1200/-1600/-2048` × `webp/avif/jpg` + `-lqip.webp`），不覆盖原图。
3. **透明底例外**：`三明治图` `Group 3` `技术路线` `制作流程图` 保留 alpha（WebP/AVIF 支持），不要被默认 flatten 规则压成黑底。JPEG fallback 才压到 `#0f0f0f`。
4. **视频真裁真转**：所有视频用 ffmpeg 实际裁剪/缩放/去音轨，不用 CSS 截取代替。
5. **不做 4K 下发**：手机档最大 1200 宽；桌面最大 2048 宽。8K 延时素材只抽帧，不转视频。
6. **不伪造过程**：Blender/3D 过程 reel 只从用户真实录屏截取，不合成、不补帧、不生成不存在的工程画面。
7. **隐私**：获奖证书沿用现有公开版/打码版；5 分钟成片中含团队成员出镜的段落**不截取**。
