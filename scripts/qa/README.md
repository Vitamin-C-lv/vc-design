# scripts/qa — 本地验收工具

不属于应用构建，`app/` 与 `components/` 不引用这里的任何东西。依赖独立于站点运行时（`package.json` 在本目录）。

## 装依赖

```bash
cd scripts/qa && npm install
```

## 怎么跑

先起站点（**另开一个终端**，`next start` 会一直占着）：

```bash
cd vc-site && npx next start -p 3000
```

再跑脚本：

```bash
node scripts/qa/diag-load.mjs     # 只问一句"站点现在能不能打开"
node scripts/qa/shoot.mjs         # 全站回归（最慢，几分钟）
```

## 工具

| 脚本 | 用途 | 判据 |
|---|---|---|
| `diag-load.mjs` | 真实浏览器完整加载首页，抓失败请求 / 4xx-5xx / JS 错误 | 标题正确、正文非空、三项均为 0。**判断"网站能不能打开"的首选**——`curl` 只看 HTML 状态码，验不出子资源失败 |
| `shoot.mjs` | 权威全站回归：7 路由 × 4 视口 + 微信 UA + reduced-motion + 无 JS | 无水平溢出、无未揭示元素、无破图、0 控制台错误 |
| `layout-audit.mjs` | 溢出 / 破图 / 压页头 / 死白 / 小字（<11px） | 全路由 OK（无 <11px 文本——汉字在 10px 会丢字怀） |
| `narrow-type.mjs` | 「一行一个字」探测器（元素宽度 < 字号 ×1.9） | 全路由 OK |
| `probe-home-blocks.mjs` | 首页四个旗舰各自跑起了什么 | 古格 video、观潮 iframe（`/guanchao-live`）、青花 canvas、李花花只有静态封面；全页各 1 |
| `check-underline.mjs` | 链接下划线在**静止态**是否可见 | 静止 `opacity: 0.4`，悬停 `1` |
| `verify-guge-video.mjs` | 古格视频是否真的在播 | `paused:false`、`src` 指向 `mengu-loop`、请求 200/206 |
| `verify-particle.mjs` | 青花粒子：兜底图是否退场、是否绘制、器物是否被裁切、切阶段是否重绘 | 四项断言全过 |
| `verify-snapshot.mjs` | 观潮内嵌副本可用性 | 标题正确、4xx/5xx 为 0、帧内导航可点 |
| `verify-decode.mjs` | 点云解码正确性（纯 Node，**不需要站点在跑**） | 解出的 bbox 逐轴等于 `pointcloud.json` 的 bbox |
| `verify-fastscroll.mjs` | 快速滚动（冷启动 + 真实滚轮猛甩）下懒加载是否既够懒、又不会卡死 | 案例页静置不滚动时点云 0 请求、canvas 仍 300×150；首页冷启动猛甩后点云被请求且 canvas 已按真实尺寸初始化；视口内无未揭示元素 / 未加载图片 |
| `verify-headline.mjs` | 标题逐行揭示的断行与首页列宽适配回归 | 案例页行拼回隐藏槽位里的完整 `titleZh`、切口不切拉丁单词、不以中文收尾标点开头且每行只占一视觉行；首页 390/768/1024/1280/1440/1728px 六档下四个旗舰标题每行只占一视觉行且不超 `container-type` 父列宽 |
| `verify-reveal-instant.mjs` | 快滚门限 `data-reveal-instant` 不能两头失效：既不能误伤阅读速度下的揭示动画，也不能甩完不摘掉、导致全站从此没有揭示动画 | 静止时 `rise`/`fade` 过渡为 `0.9s, 1.044s`、`masked` 子元素为 `1.05s`；猛甩期间两者塌成 `0s` 且标记出现；停下后标记摘掉、过渡恢复；阅读速度（110px/280ms）全程标记**不出现**且能采到真实的动画中间态（opacity 或 clip-path）。时序敏感，单次失败先重跑一次再判定 |

## 环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `BASE` | 目标地址。**所有需要站点的脚本都认**（`shoot.mjs` 还额外接受第一个命令行参数） | `http://127.0.0.1:3000` |
| `CHROMIUM` | chromium 可执行文件路径 | `/usr/bin/chromium` |

例：`BASE=http://127.0.0.1:4000 node scripts/qa/shoot.mjs`

## 约定

- 输出写到仓库根 `_qa-output/`（已 gitignore）。路径一律从 `ROOT`（`fileURLToPath(new URL('../../', import.meta.url))`）推出来，**不要写死绝对路径** —— 仓库路径里有中文，写死了换台机器就废。
- **加了新探测器就写进上表**，否则下一个人不知道它存在、也不会跑。
- 只留"还能跑、且有判据"的脚本。一次性的排查脚本用完就删，不要堆在这里。
- 判据写在脚本里、也写在上面这张表里。**表里写了判据、脚本里却没有断言**，等于这条探测器不存在——`probe-home-blocks.mjs` 一开始就是这样，只能肉眼看它打印的表格。

## ⚠️ 这些脚本的输出是假设，不是判决

三条实测教训，写在脚本里比写在文档里管用：

1. **失败先怀疑脚本自己过期了。** 这里所有脚本曾经把地址写死成 `http://127.0.0.1:3000`、把输出目录写死成这台机器的绝对路径。服务换端口后它们集体报 FAIL，而失败样本里赫然是浏览器自己的错误页文案 `refused to connect`——差一点被误判成"服务被回收"。所以现在**一律**走 `BASE` 和 `ROOT`。
2. **报通过也不代表没缺陷。** 曾经出现过"所有自动化指标全绿"与"每个汉字占一行、页面被撑高 4240px"同时存在。改完界面**要用真实截图亲眼看一遍**。
3. **规避误报的豁免必须做反向测试。** `layout-audit.mjs` 的溢出检查会跳过"某个祖先能横向滚动"的元素（首页图像卷轴本来就比视口宽，是设计意图；不豁免的话恒报 4 条，会把真溢出埋掉）。加了这种豁免后，要拿一个**真的**溢出元素验一遍它还抓得到，否则等于把探测器关了。
4. **改了环境变量支持，要拿一个错的地址反向验一遍。** 只验"默认值下能过"证明不了脚本真的读了 `BASE`。
